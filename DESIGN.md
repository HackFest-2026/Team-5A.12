# CashPilot Design System

Mode: Operate.

## Visual direction

Quiet financial command center: warm off-white canvas, ink typography, compact white work surfaces, emerald for healthy cash, amber for attention, coral for exposure. Dense information is organized through rhythm and hierarchy instead of borders everywhere.

## Tokens

- Canvas: `#f4f5ef`
- Surface: `#ffffff`
- Ink: `#18201c`
- Muted: `#6d756f`
- Brand: `#176b50`
- Attention: `#bf7a17`
- Danger: `#c95045`
- Border: `#dfe3dc`
- Radius: 16px surfaces, 10px controls

Typography uses the system sans stack. Numeric values use tabular figures. Motion is limited to state changes and navigation feedback.
